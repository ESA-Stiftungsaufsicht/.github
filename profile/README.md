## Willkommen

Dies ist die GitHub-Organisation der Eidgenössischen Stiftungsaufsicht (ESA). Sie bietet einen gemeinsamen Ort für technische Zusammenarbeit und die Pflege von Projekten.

## Orientierung

| Bereich | Hier finden Sie |
| --- | --- |
| Repositories | Die für Sie freigegebenen Projekte und ihre Dokumentation |
| Zusammenarbeit | Nachvollziehbare Änderungen und technische Rückmeldungen im jeweiligen Projekt |
| Informationen zur ESA | Aufgaben, Dienstleistungen und Kontaktmöglichkeiten auf der [ESA-Website](https://www.esa.admin.ch/de/aufsicht) |

## Für Organisationsmitglieder

Nach der Anmeldung steht die interne Organisationsansicht mit Projektlinks und Arbeitsmitteln zur Verfügung. Die Sichtbarkeit einzelner Repositories richtet sich nach Ihren Berechtigungen.
